## Önemli düzeltmeler
- Ponytail bağımsız resmî GitHub deposundan kurulabilir.
- Headroom CLI ile deneme sonrası ücretli masaüstü uygulaması aynı ürün koşullarına sahip değildir.
- Graphify paketi `graphifyy`, komutu `graphify`.
- CodeBurn için Node.js 22.13.0+ kullanılmalıdır.
- Tasarruf yüzdeleri göreve, sürüme ve ölçüm metoduna bağlıdır.
